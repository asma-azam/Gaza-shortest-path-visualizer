# Gaza Shortest Path Visualizer

## Project Overview
An interactive desktop application developed using Java and JavaFX to calculate and visualize the shortest path between locations in the Gaza Strip using Dijkstra's algorithm.

## Technologies Used
- Java
- JavaFX
- Dijkstra's Algorithm
- Graph Data Structures
- Eclipse IDE

## Main Features
- Interactive map of Gaza.
- Select a starting location and destination.
- Calculate the shortest path using Dijkstra's algorithm.
- Display the calculated route visually on the map.
- Read map and location information from data files.

## Project Structure
- `src/application/` — Java source code.
- `data/` — Map and location data.
- `images/` — Images and graphical resources.

## How to Run
1. Open the project in Eclipse IDE.
2. Configure JavaFX libraries.
3. Run `Main.java`.
